# Calcula UAT Web Application

Calcula UAT is an educational software platform designed to support structured mental calculation practice and descriptive learning analytics.

This repository contains the web component of Calcula UAT. The application is intended for institutional users responsible for organizing mathematical content, creating and managing exercises, and inspecting interaction statistics generated by the companion Android application.

The web application is developed with Next.js and React and uses Firebase Cloud Firestore as the shared cloud data layer.

## Main features

- Institutional registration and access.
- Creation and management of mathematical categories and subcategories.
- Creation, editing, filtering, and removal of mathematical problems.
- Classification of problems by academic level, category, subcategory, and difficulty.
- Support for mathematical expressions using MathJax-compatible components.
- Retrieval of interaction records generated by the Calcula UAT mobile application.
- Visualization of descriptive learning-analytics indicators.
- Filtering of problems before statistical analysis.

## Learning analytics

For a selected mathematical problem, the web application processes interaction records stored in Cloud Firestore.

The current analytics interface includes:

- total number of recorded responses;
- average elapsed response time;
- comparison between problems solved on the first attempt and those requiring multiple attempts;
- distribution of response times;
- relationship between number of attempts and elapsed response time.

The current version provides descriptive analytics. It does not implement automated diagnosis, predictive modeling, or adaptive recommendation.

## Installation

Clone the repository:

```bash
git clone https://github.com/Benevos/academic-web-app-v2.git
```

Enter the project directory:

```bash
cd academic-web-app-v2
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the application in a web browser at:

```text
http://localhost:3000
```

To create a production build:

```bash
npm run build
```

To run the production build:

```bash
npm start
```

## Firebase configuration

The application uses Firebase Cloud Firestore as its data layer.

The Firebase configuration is currently defined in:

```text
src/services/firebase.js
```

The Calcula UAT platform uses the following principal Firestore collections:

- `institutions`
- `categories`
- `problems`
- `responses`

A compatible Firebase project and Firestore database are required to reproduce the complete system.

Detailed information about the structure of these collections will be provided in the project documentation.

## Data model overview

### institutions

Stores institutional information used by the current research prototype, including the institutional key, institution name, enabled academic levels, and access information.

### categories

Stores categories and subcategories associated with an institution.

### problems

Stores mathematical exercises created through the web application, including:

- institutional key;
- title;
- problem statement;
- category;
- subcategory;
- difficulty;
- academic level;
- answer alternatives;
- correct-answer identifier.

### responses

Stores interaction data generated by the mobile application, including:

- institutional key;
- problem identifier;
- number of attempts required to reach the correct answer;
- elapsed response time;
- interaction date.

## Relationship with the mobile application

The web and mobile applications communicate with the same Cloud Firestore data layer.

The web application creates and organizes educational content. The Android application retrieves that content, presents mathematical exercises to users, and records interaction data.

The web application subsequently retrieves those interaction records to generate descriptive statistics.

The companion mobile repository is available at:

https://github.com/Benevos/academic-mobile-app

## Current status

Calcula UAT v2.0.0 is a research software prototype intended for educational experimentation and research.

The current institutional access mechanism was designed for controlled research deployments and should not be considered a production-grade identity-management system.

Authentication, access-control policies, accessibility, and deployment hardening remain areas for future development.
